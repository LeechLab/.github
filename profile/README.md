# LeechLab

### _By gamers, for gamers._

LeechLab creates games for players to enjoy. We craft masterful games with focus, effort, and vision, all for the love of the game.

---

## About Us

We're a passion-driven game studio. We don't chase money; we chase great games. Like Valve, we want to push innovation forward, and we make games because we love making them and want to share that passion with the world.

## Our Goals

- **Innovate:** Push ideas, mechanics, and technology forward.
- **Create with passion:** Every project is built out of love for the game, not for profit.
- **Share the experience:** Bring our games to as many players as possible, on as many platforms as possible.
- **Build with craft:** Focus, effort, and vision in everything we ship.

## What We Make

## Brand Guidelines

Our look is a moody, dark UI with red as the signature color. Light gray is used for text, and orange is reserved for accents and hover states.

| Role               | Color                  | Hex         |
| ------------------ | ---------------------- | ----------- |
| **Primary brand**  | Red                    | `#e6281e`   |
| **Text**           | Light gray             | `#cecece`   |
| **Accent / hover** | Orange                 | `#ff8000`   |
| **Background**     | Semi-transparent black | `#0000008a` |
| **Hidden / muted** | Dark gray              | `#404040`   |
| **Dark red**       | Deep red               | `#1b0404`   |

### CSS Variables

```css
:root {
  --primary-color: #cecece; /* text color */
  --red-color: #e6281e; /* true brand primary */
  --hover-color: #ff8000; /* accent / hover */
  --background-color: #0000008a;
  --hidden-color: #404040;
  --darkred-color: #1b0404;
}
```

> **Note:** `--red-color` is our actual primary brand color. `--primary-color` is the light gray we use for text.
